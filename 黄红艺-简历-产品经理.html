03代表项目

01

华为 Answer 2.0 AI 办公｜企业级 Agent 工作伙伴

产品经理 + 体验设计 · 双角色

S 背景
信息散在 WeLink 文档、群聊、知识中心与代码仓库，跨系统办事要反复复制粘贴；知识源有 3 个入口，全量用户中仅约 700 人使用且极易选错。
T 任务
以 PD + UXD 双角色负责能力边界、产品骨架、状态化交互与反馈闭环；目标是让用户只记一个入口、敢把任务交出去、失败时知道为什么。
A 行动
确立「Chat 是入口、垂域是能力」，子代理封装为工具由主 Agent 调度；知识源三入口收敛为一个下拉，改由 Agent 消解冲突；状态写成枚举——无输出不出现复制/分享，失败不出现点赞；反馈改为两级标签并自动映射跟进人；内审推行「先画理想链路，再推架构」。
R 结果
覆盖 近 1000 人，试点团队满意度 4.2；入口 3 → 1；反馈可定位（7.1–7.20 共 85 条，BUG 22 条，按模块分派）；沉淀 Agent 设计体系 45 个组件。
